# Linear Algebra in Python — runnable notebooks (public mirror)

This repository is the **public, runnable mirror** of *Linear Algebra in Python
— A Notebook Course in Matrices, Algorithms, and Learning* by Raymond Amador.

- 📖 **Read the rendered course:** <https://ramador09.github.io/linear-algebra-in-python-public/>
- ▶️ **Run a notebook:** use the **Binder** or **Colab** button on any page of
  the course, or open a file under [`notebooks/`](notebooks/) directly.

## What is here, and what is not

The notebooks are **solution-stripped**: each problem statement, every figure,
and every ✓/✗ check result is present, but the reference implementations are
not. That is deliberate — the exercises are the course. Instructors who want the
worked solutions should get in touch (see the Preface).

Stored outputs are cleared, so the files are small and Binder starts quickly.
Run the cells to regenerate everything.

## Status

Complete: all 55 notebooks across ten chapters, a Prologue and an Epilogue.
Each notebook executes end to end on every commit, and every one of its checks
passes before the mirror is republished.
